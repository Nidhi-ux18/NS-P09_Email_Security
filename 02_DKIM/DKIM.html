DKIM Cryptographic Verification

This module demonstrates DKIM-style digital signing and cryptographic verification.

DKIM Components

Private Key: Used by the sender to create the digital signature.

Public Key: Used to verify the signature.

Selector: Identifies which DKIM public key should be used.

Domain: Identifies the domain responsible for the signature.
